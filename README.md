# 🚌 BusSnake - האקתון AI אגד

משחק Snake רב-משתתפים בזמן אמת, בו כל אוטובוס באגד מהווה חדר משחק נפרד.
נוסעים סורקים QR בתוך האוטובוס ומצטרפים למשחק - הנחש שלהם הוא אוטובוס שאוסף נוסעים מפוזרים על הכביש.
שחקנים יכולים לאכול אחד את השני; כשמישהו מת, הנוסעים שאסף הופכים ל"אוכל" זמין לכולם.

## ✨ פיצ'רים

- חדר משחק לכל אוטובוס (לפי `busId`)
- 5-15 שחקנים בו-זמנית בקלות
- כניסה ב-QR או ב-URL ישיר (`/play?bus=24A`)
- עובד על נייד (swipe + כפתורי מסך) ועל מחשב (חצים / WASD)
- אם נוסע מתנתק זמנית (האפליקציה ברקע / מסך ננעל) - הנחש שלו פשוט נעצר וממתין
- מוות → respawn מיידי בלחיצת כפתור
- HUD עם טבלת מובילים בזמן אמת
- הכל בעברית, RTL

## 🛠️ Stack

- **Backend:** Node.js + Express + Socket.IO
- **Frontend:** HTML5 Canvas + Vanilla JS (ללא בנייה, ללא תלות)
- **QR:** ספריית `qrcode`
- **Architecture:** Server-authoritative — השרת מנהל את לוגיקת המשחק, הלקוח רק שולח קלט ומצייר

## 🚀 הרצה מקומית

דרישות: Node.js 18 ומעלה.

```bash
npm install
npm start
```

פתחו `http://localhost:3000` בדפדפן.
לכניסה ישירה למשחק: `http://localhost:3000/play?bus=demo`

### בדיקה מולטיפלייר באותו מחשב

פתחו 2-3 חלונות (Incognito עוזר) ב-URL:
```
http://localhost:3000/play?bus=demo
```
תנו לכל אחד שם אחר ותראו את כולם מתרוצצים באותה מפה.

### בדיקה מנייד באותה רשת WiFi

1. גלו את ה-IP המקומי של המחשב (`ipconfig` ב-Windows)
2. פתחו בנייד `http://<IP>:3000/?bus=demo`

## ☁️ דפלוי ל-Render.com (חינמי)

1. דחפו את הקוד ל-GitHub repo חדש.
2. ב-[Render.com](https://render.com) - **New > Web Service**.
3. חברו את ה-repo.
4. הגדרות:
   - **Runtime:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
5. Deploy. הקישור שתקבלו (`https://<app>.onrender.com`) - זה ה-URL שלכם.

> ⚠️ **שימו לב:** ב-Free Tier השירות "נרדם" אחרי 15 דק' חוסר פעילות, ולוקח לו ~50 שניות לעלות חזרה.
> **לפני ההדגמה בכנס - פתחו את הדף 2-3 דקות מראש** כדי לחמם אותו.

## 🎮 איך משחקים

1. סרקו את ה-QR או פתחו `/play?bus=<מזהה>`.
2. הקלידו שם.
3. ניתוב:
   - **מחשב:** חצים או WASD
   - **נייד:** swipe על המסך, או כפתורי הכיוונים בתחתית
4. אכלו אנשים → גדלו.
5. נכנסתם בנחש אחר → מתם → לחצו respawn והמשיכו.
